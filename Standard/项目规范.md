### 项目结构规范

Unity 项目 Assets 下推荐按**功能模块**组织，采用**大驼峰命名法（PascalCase）**。

**推荐结构**

这样做的好处是

- 与第三方资源隔离，自己的资源一直在最上面，第三方的在下面
- 防止误操作，第三方资源包更新时有时会覆盖文件，你的资源在独立目录里不会被波及。

### 资源命名规范

```
[类型前缀]_[模块/功能]_[描述]_[变体]
```

例如

| 资源类型         | 命名规则      | 示例                                          |
| ---------------- | ------------- | --------------------------------------------- |
| 脚本             | PascalCase    | `PlayerController.cs`                         |
| 预制体           | PFB_功能名    | `PFB_Player`, `PFB_Goblin`                    |
| 材质             | MAT_名称      | `MAT_PlayerSkin`, `MAT_Rock`                  |
| 贴图             | Tex_名称_类型 | `Tex_Player_D`(Diffuse), `Tex_Rock_N`(Normal) |
| 动画片段         | ANI_角色_动作 | `ANI_Player_Run`, `ANI_Boss_Attack`           |
| 动画控制器       | AC_角色名     | `AC_Player`, `AC_Goblin`                      |
| ScriptableObject | SO_类型_名    | `SO_Item_Sword`, `SO_Skill_Fireball`          |
| 场景             | 直接语义名    | `MainMenu`, `Level_01`                        |
| 音效             | SFX_描述      | `SFX_Sword_Hit`, `SFX_Player_Jump`            |
| 背景音乐         | BGM_描述      | `BGM_BossFight`, `BGM_Village`                |
| 粒子特效         | VFX_描述      | `VFX_BloodSplash`, `VFX_FireBall`             |
| Shader           | SHD_描述      | `SHD_Dissolve`, `SHD_Outline`                 |

**用 Assembly Definitions（.asmdef）隔离模块**，避免全局编译耦合，Scripts 下每个子文件夹都建议配一个。

**ScriptableObject 驱动数据**，把角色属性、技能、物品等数据抽出来做 SO，方便策划调整、不用改代码。

**Prefab Variants** 灵活运用，比如各种敌人共享一个 Base Enemy Prefab，各自做 Variant 覆盖差异。

**Scene 分层管理**：MainMenu / Loading / Gameplay 场景分离，Gameplay 内用 Additive Scene 加载关卡，方便团队协作和分模块开发。



### C#代码规范

```C#
// ✅ 类名、方法名、属性名 → PascalCase
public class PlayerController : MonoBehaviour { }
public void TakeDamage(int amount) { }
public int MaxHealth { get; private set; }

// ✅ 私有字段 → _camelCase（下划线前缀）
private int _currentHealth;
private Rigidbody _rigidbody;

// ✅ 公开字段（尽量少用） → PascalCase
public float MoveSpeed = 5f;

// ✅ 局部变量、参数 → camelCase
int damageAmount = 10;
void Attack(GameObject target) { }

// ✅ 常量 → ALL_CAPS 或 PascalCase（Unity 社区更倾向后者）
private const int MaxComboCount = 5;

// ✅ 接口 → I 开头
public interface IAttackable { }
public interface IDamageable { }

// ✅ 枚举 → PascalCase，成员也是 PascalCase
public enum CharacterState { Idle, Running, Attacking, Dead }

// ✅ 事件 → On 前缀 或 动词过去时
public event Action OnDeath;
public event Action<int> OnHealthChanged;
```



### 类内部顺序

```c#
public class PlayerController : MonoBehaviour
{
    // 1. 常量
    private const float GroundCheckRadius = 0.2f;

    // 2. 序列化字段（Inspector 可见）
    [Header("Movement")]
    [SerializeField] private float _moveSpeed = 5f;
    [SerializeField] private float _jumpForce = 8f;

    [Header("Combat")]
    [SerializeField] private int _maxHealth = 100;

    // 3. 私有字段
    private Rigidbody _rb;
    private int _currentHealth;
    private bool _isGrounded;

    // 4. 属性
    public int CurrentHealth => _currentHealth;
    public bool IsDead => _currentHealth <= 0;

    // 5. 事件
    public event Action OnDeath;
    public event Action<int> OnHealthChanged;

    // 6. Unity 生命周期（按执行顺序排）
    private void Awake() { }
    private void OnEnable() { }
    private void Start() { }
    private void Update() { }
    private void FixedUpdate() { }
    private void OnDisable() { }
    private void OnDestroy() { }

    // 7. 公开方法
    public void TakeDamage(int amount) { }
    public void Heal(int amount) { }

    // 8. 私有方法
    private void HandleMovement() { }
    private void Die() { }

    // 9. Unity 回调（碰撞、触发器）
    private void OnTriggerEnter(Collider other) { }
    private void OnCollisionEnter(Collision collision) { }

    // 10. Gizmos（调试用）
    private void OnDrawGizmosSelected() { }
}
```
